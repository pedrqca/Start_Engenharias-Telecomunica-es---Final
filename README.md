# Start_Engenharias: Telecomunicações

O Start_Engenharias é um launcher web para apoiar as atividades de Telecomunicações. Ele reúne materiais de consulta e cartas de ajuda para orientar as equipes durante os desafios.

## Aplicação

Acesse o projeto em produção:

<https://start-telecom-final.vercel.app/>

## Funcionalidades

- Acesso à apostila com material didático e guia de práticas.
- Consulta à tabela de cores para LED RGB.
- Navegação por cartas de ajuda com carrossel.
- Exibição dos detalhes de cada carta, incluindo contexto, efeito, exemplos e função.
- Seleção de uma carta para utilização pelo grupo.
- Visualização da carta selecionada em tela cheia.
- Validação da senha da organização para liberar o uso da carta.
- Registro do histórico de cartas utilizadas e de quem autorizou cada uso no navegador.

## Observação

A validação das senhas acontece no navegador. Esse mecanismo não deve ser considerado uma autenticação segura; para proteger informações de forma efetiva, as senhas precisariam ser verificadas em um servidor.
